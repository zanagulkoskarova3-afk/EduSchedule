# Ақылды кесте / Smart Schedule KZ

5–11 сыныптарға арналған жылдық және тоқсандық сабақ кестесін автоматты құратын екі тілді (қазақша / English) веб-сайт. Таза JavaScript, сервер қажет емес, жасанды интеллект (Google Gemini / Claude API) интеграциясы бар.

## Іске қосу

1. Sublime Text-те: **Project → Open Project…** → `school-schedule.sublime-project` файлын ашыңыз.
2. `index.html` файлын браузерде ашыңыз (екі рет басу жеткілікті).
3. Ыңғайлы болу үшін жергілікті сервер: `python -m http.server 8000` → http://localhost:8000

## Сервер: Firebase (v3)

Сайт екі режимде жұмыс істейді:

| Режим | Қашан | Деректер қайда |
|---|---|---|
| ☁ **Firebase** | `firebase-config.js` толтырылған | Google Firebase бұлтында — кез келген компьютерден кіруге болады |
| 💾 **Серверсіз** | `firebase-config.js` бос | Тек осы браузерде (интернетсіз демо үшін) |

Режим кіру бетінің төменгі жағында және «Пайдаланушылар» бетінде көрсетіледі. Жоғарғы панельдегі белгі (☁ Сақталды / ⟳ Сақталуда… / ⚠ Сақталмады) деректердің серверге жеткенін көрсетеді. Өзгерістер 1–2 секундта автоматты түрде сақталады.

### Firebase-ті қосу (бір рет, ~10 минут)

1. https://console.firebase.google.com → **Add project** → атауы, мысалы `akyldy-keste` (Google Analytics қажет емес).
2. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save.**
3. **Build → Firestore Database → Create database** → орны (location) кез келген, мысалы `europe-west` → **Start in production mode**.
4. Firestore-дың **Rules** бетіне `firestore.rules` файлының ішіндегісін толық көшіріп, **Publish** басыңыз.
5. **⚙ Project settings → General → Your apps → `</>` (Web)** → қосымшаны тіркеңіз → `firebaseConfig` мәндерін `firebase-config.js` файлына көшіріңіз.
6. Сайтты **http** арқылы ашыңыз:
   - компьютерде: `python -m http.server 8000` → http://localhost:8000 (файлды екі рет басып ашу Firebase-пен дұрыс жұмыс істемеуі мүмкін);
   - интернетте: GitHub Pages. Сосын **Authentication → Settings → Authorized domains**-қа `сіздің-атыңыз.github.io` доменін қосыңыз.
7. Сайтты ашыңыз → алғашқы рет **әкімші аккаунтын** құрасыз → «👥 Пайдаланушылар» бетінен басқаларды тіркейсіз.

Firebase тегін жоспары (Spark) мектепке жеткілікті: тәулігіне 50 000 оқу, 20 000 жазу, 1 ГБ орын.

### Аккаунттар

- **Әкімші** пайдаланушыларды тіркейді (аты-жөні, логин, құпиясөз, рөлі; 🎲 — кездейсоқ құпиясөз), бұғаттайды, рөлін өзгертеді, жояды, «📂 Ашу» арқылы кез келген пайдаланушының деректерін ашып, көмектесе алады.
- Логин ретінде қарапайым сөз (`aigerim`) немесе нақты email жазуға болады. Жүйе ішінде `aigerim` → `aigerim@eduschedule.local` болып сақталады.
- Әр пайдаланушы 🔑 арқылы өз құпиясөзін өзгертеді.
- **Әр аккаунттың деректері бөлек:** мектеп, мұғалімдер, жүктеме, кестелер, ҚТЖ/ОМЖ. AI кілті тек сол браузерде сақталады (серверге жіберілмейді).

### Firebase-тің шектеулері (тегін жоспарда)

- Әкімші басқа адамның құпиясөзін өзі өзгерте алмайды (бұл үшін ақылы Cloud Functions керек). Пайдаланушы құпиясөзін өзі өзгертеді. Логин орнына нақты email берілсе, «🔑 Құпиясөз» батырмасы құпиясөзді қалпына келтіру хатын жібереді. Ұмытқан жағдайда аккаунтты бұғаттап, жаңа логинмен тіркеңіз.
- Жойылған пайдаланушының логинін қайта қолдану үшін оны **Firebase Console → Authentication → Users** бөлімінен де өшіріңіз.

### Әділқазыларға: «Деректер қайда сақталады?»

- **Аккаунттар** — Google Firebase Authentication-да. Құпиясөздерді біз мүлде көрмейміз, Google оларды шифрланған (хэш) түрде сақтайды.
- **Мектеп деректері** — Google Cloud Firestore дерекқорында: `users` (профильдер), `states` (әр аккаунттың кестесі, мұғалімдері т.б.). Үлкен деректер 1 МБ-тан аспайтын бөліктерге бөлініп сақталады.
- **Қауіпсіздік** — `firestore.rules` ережелері сервер жағында тексеріледі: пайдаланушы тек өз деректерін көреді, тек әкімші барлығын көріп, пайдаланушыларды тіркей алады, бұғатталған аккаунт ештеңе оқи алмайды. `firebase-config.js` ішіндегі кілттер құпия емес, олар тек жобаны анықтайды.
- **Интернет үзілсе** — Firestore өзгерістерді браузерде ұстап тұрады, байланыс қалпына келгенде жібереді. Белгі ⚠ болса, оны басып, қайта сақтауға болады.

### Серверсіз режимнен Firebase-ке көшу

Ескі деректерді көшіру: серверсіз режимде **Мектеп → JSON сақтау**, Firebase-ке кіргеннен кейін **Мектеп → JSON ашу**.

## Мұғалімдерді Excel-ден жүктеу (v2)

**Мұғалімдер → Excel-ден жүктеу**:

1. «⬇ Үлгі (шаблон)» — дайын Excel үлгісін жүктеп алыңыз (екінші парақта барлық пәндер тізімі бар).
2. Толтырыңыз: `Аты-жөні | Пәндері | Макс. сағат/апта | Әдістемелік күн`.
   - Пәндерді үтірмен бөліп жазыңыз: `Математика, Алгебра, Геометрия`.
   - Пән атауын қазақша, орысша немесе ағылшынша жазуға болады (`Русский язык`, `Физкультура`, `English`…).
   - Әдістемелік күн: `Сәрсенбі`, `среда`, `3` т.с.с. Бос қалдыруға болады.
3. «⬆ Файл таңдау» → алдын ала қарау кестесі шығады (танылмаған пәндер қызылмен көрсетіледі) → «Импорттау».
   - «Бар тізімге қосу» — аты бірдей мұғалім жаңартылады, қалғандары қосылады.
   - «Тізімді толық ауыстыру» — ескі тізім, жүктеме және кестелер өшіріледі.

`.xlsx`, `.xls` және `.csv` қабылданады. Excel файлын оқу үшін SheetJS кітапханасы интернеттен жүктеледі; интернет жоқ болса, файлды CSV түрінде сақтап жүктеңіз. «Excel-ге сақтау» — қазіргі тізімді Excel-ге шығарады.

## Жұмыс тәртібі

| Қадам | Бет | Не істеледі |
|---|---|---|
| 0 | Кіру | Логин мен құпиясөз (әкімші береді) |
| 1 | Мектеп | Әр параллельдегі сынып саны, топқа бөлу, 5/6 күндік апта, тоқсан күндері, мерекелер |
| 2 | Мұғалімдер | Қолмен немесе **Excel-ден** қосу: аты-жөні, пәндері, макс. сағат, әдістемелік күн |
| 3 | Оқу жоспары | Үлгілік оқу жоспары бойынша апталық сағаттар (түзетуге болады), жылдық сағаттар есебі |
| 4 | Жүктеме | **Автоматты тағайындау** — компьютер мұғалімдерді сыныптарға бөледі, тарификация |
| 5 | Кесте | Тоқсанға / 4 тоқсанға кесте құру, сынып / мұғалім / жалпы көрініс, қолмен түзету, Excel, басып шығару |
| 6 | ҚТЖ / ОМЖ | Сабақ күндері кестеден есептеледі, тақырыптарды AI толтырады |
| 7 | AI көмекші | Кестені СанПиН бойынша талдау және чат |
| 8 | Пайдаланушылар | Тек әкімшіге: аккаунттарды басқару |

Тез сынап көру үшін: **Мектеп → Демо деректерді жүктеу → Жүктеме → Автоматты тағайындау → Кесте → 4 тоқсанға құру**.

## Алгоритм ережелері

Қатаң: мұғалім бір уақытта екі сыныпта болмайды · сыныпта «терезе» жоқ · күнделікті сабақ шегі (5–6 сынып: 6, 7–11 сынып: 7) · әдістемелік күн бос · бір пән күніне 2-ден көп емес.

Жұмсақ (СанПиН): қиын пәндер 2–4 сабақта · сейсенбі/сәрсенбі ең ауыр, дүйсенбі/жұма жеңіл · бір пән бір күнде қайталанбайды · мұғалімдердің терезесі аз.

Әдіс: жинақы бастапқы орналастыру + имитациялық күйдіру (simulated annealing).

## AI баптауы

**Баптаулар** → Google Gemini (тегін) немесе Claude API кілтін енгізіңіз. Кілт серверге жіберілмейді: тек браузердің localStorage-інде, әр аккаунтқа бөлек сақталады.

## Файлдар

```
index.html          — бүкіл сайт (төмендегі бөлімдер)
firebase-config.js  — Firebase кілттері (бос болса — серверсіз режим)
firestore.rules     — Firestore қауіпсіздік ережелері (Firebase Console-ға көшіріледі)
```

`index.html` ішіндегі бөлімдер:

```
<style>              — дизайн, басып шығару стилі
i18n.js бөлімі       — қазақша / ағылшынша мәтіндер
data.js бөлімі       — пәндер, үлгілік оқу жоспары, СанПиН, оқу жылы күндері, демо
assign.js бөлімі     — мұғалімдерді автоматты тағайындау
scheduler.js бөлімі  — кесте құрастыру алгоритмі
ai.js бөлімі         — Gemini / Claude API: талдау, ҚТЖ, ОМЖ, чат
app.js бөлімі        — интерфейс логикасы + Excel импорт/экспорт
auth.js бөлімі       — аккаунттар, кіру, әкімші панелі, Firebase / жергілікті сақтау
```

## Маңызды ескерту

Ішіндегі апталық сағаттар мен СанПиН шектері ҚР үлгілік оқу жоспарына жуықтап толтырылған. Мектептің оқыту тілі мен ағымдағы Оқу-ағарту министрлігінің бұйрығына сай «Оқу жоспары» бетінде тексеріп, түзетіңіз. Тоқсан күндері 2026–2027 оқу жылына министрлік бекіткен мерзім бойынша қойылған.
